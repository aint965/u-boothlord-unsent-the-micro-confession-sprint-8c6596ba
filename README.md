# Unsent: The Micro-Confession Sprint

One unsent message, typed and never sent: a confession to Dad about a guitar sold years ago and a lie about it being stolen that has been kept up ever since. It is short, specific, and ashamed — the kind of thing that stays in drafts because saying it out loud now would mean admitting how long the lie has lasted.
